# Mini CRM для малого бізнесу: Telegram-бот + сайт + панель заявок

Демо-проєкт для барбершопу **BLADE Barber Studio** (бізнес вигаданий).
Клієнт записується через Telegram-бота або форму на сайті → заявка зберігається в базі →
власник миттєво отримує сповіщення в Telegram і веде заявки в веб-панелі.

**Лендинг наживо:** _посилання на GitHub Pages_
**Демо-відео:** _посилання_

## Що вміє

**Telegram-бот (клієнт)**
- запис у 4 кроки: ім'я → послуга (кнопки) → телефон (кнопка «Поділитися номером» або текст) → зручний час;
- валідація введених даних, скасування на будь-якому кроці;
- клієнт отримує повідомлення, коли заявку взяли в роботу.

**Telegram-бот (власник)**
- миттєве сповіщення про кожну нову заявку — з бота і з сайту;
- зміна статусу кнопками прямо в чаті: «В роботі» / «Виконана» / «Відмова»;
- команди `/leads` (останні заявки) і `/stats` (статистика).

**Веб-панель `/admin`**
- список заявок, фільтр за статусом, лічильники «сьогодні / всього / за статусами»;
- зміна статусу, клікабельні телефон і Telegram клієнта;
- автооновлення кожні 10 секунд, захист паролем (HTTP Basic).

**Лендинг `docs/`**
- адаптивний (iPhone, Android, десктоп), анімації появи, 3D-нахил карток, анімований барбер-пол;
- форма запису надсилає заявку в ту саму CRM через API;
- захист від спаму: приховане поле-пастка і ліміт заявок з однієї IP.

## Стек
Python 3.11+ · aiogram 3 · aiohttp · SQLite · HTML / CSS / JavaScript без фреймворків.
Бот і веб-сервер працюють в одному процесі, без зовнішніх сервісів.

## Структура
```
main.py        — запуск бота й веб-сервера
bot.py         — сценарій запису, сповіщення, адмін-команди
web.py         — API заявок, панель, віддача лендингу
db.py          — робота з SQLite
config.py      — налаштування з .env
panel/         — веб-панель заявок
docs/          — лендинг (також публікується через GitHub Pages)
```

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate          # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env          # Linux/macOS: cp .env.example .env
```
Заповніть `.env`:
- `BOT_TOKEN` — токен від [@BotFather](https://t.me/BotFather);
- `ADMIN_CHAT_ID` — ваш Telegram ID (можна дізнатися в [@userinfobot](https://t.me/userinfobot));
- `PANEL_PASSWORD` — пароль до панелі.

```bash
python main.py
```
- сайт: http://127.0.0.1:8080/
- панель: http://127.0.0.1:8080/admin (логін `admin`)

Без `BOT_TOKEN` запускаються лише сайт і панель — зручно для перевірки.

## API
| Метод | Шлях | Опис |
|---|---|---|
| POST | `/api/leads` | нова заявка з сайту (публічний) |
| GET | `/api/leads?status=new` | список заявок і статистика (з паролем) |
| POST | `/api/leads/{id}/status` | зміна статусу (з паролем) |
